# Techno

### Kahit Ano • Visual Catalog & Reservation System Prototype

A clean, responsive interactive apparel catalog and reservation management prototype for college campus apparel and uniforms.

## Features
- **Visual Catalog**: High-definition studio apparel photography, live category filters (General, PE, Department, Accessories), and real-time search.
- **Smart Reservation Cart**: Size selection (XS to 3XL), quantity adjustment, live price calculation, and local storage state persistence.
- **Student Checkout**: Generates printable confirmation claim slips with custom visual QR codes.
- **Admin Logistics Dashboard**: Live reservation queue tracking, status updates (Pending, Ready for Pickup, Claimed), inventory stock level editing, and CSV masterlist export.
- **Interactive Size Guide**: Anatomical measurement tables with dual-unit toggle (Inches / Centimeters).

## Tech Stack
- HTML5, Vanilla JavaScript, CSS3
- Tailwind CSS
- Canvas Confetti
